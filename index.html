NovaBank - Banking Management System (latest diploma project)

An educational banking system built with Python, Object-Oriented Programming and Streamlit. It manages customers, savings and checking accounts, deposits, withdrawals, transfers and transaction history, and saves its data in JSON files. It is an academic simulation, not a production banking platform.

View NovaBank on GitHub

Architecture (layers)

  1. Backend: Python classes and banking rules
  2. Service layer: the Bank class coordinates customers, accounts and transactions
  3. Frontend: Streamlit web interface
  4. Persistence: JSON storage between sessions

OOP concepts used

Encapsulation
The balance and status are protected attributes, changed only through methods like deposit() and withdraw().
Inheritance
SavingsAccount and CheckingAccount inherit from Account.
Polymorphism
CheckingAccount overrides withdraw() to support an overdraft limit.
Abstraction
Simple operations hide the internal state management.
Composition
The Bank object manages Customer, Account and Transaction objects.

Custom exceptions

  • InvalidAmountError
  • InsufficientFundsError
  • AccountNotFoundError
  • DuplicateAccountError, DuplicateCustomerError and CustomerNotFoundError
